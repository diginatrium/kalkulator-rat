# /add-feature

Guided feature brainstorm and implementation planning for kalkulator-rat.

Invoke the `add-feature` skill to walk through:
1. Clarifying questions (what, scope, edge cases)
2. 3–5 implementation options with trade-offs
3. Recommended approach
4. Detailed implementation checklist (models → service → components → tests → verification)

No code is written during this command — the output is a checklist ready to execute.
